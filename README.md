# Quién la canta

Juego musical web: suena un trocito de una canción famosa y hay que adivinar quién la canta.

## Subir a GitHub Pages
1. Crea un repositorio nuevo y sube todos estos archivos a la raíz.
2. En el repositorio: Settings > Pages > Source: "Deploy from a branch" > rama `main` / carpeta `/ (root)`.
3. En un minuto estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Los fragmentos de audio vienen de las APIs públicas de iTunes y Deezer (previews de 30 s), así que hace falta conexión a internet.
